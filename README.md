## 30 秒上手（整包）

1. 确认你的游戏是 **卫戍协议：盟约 v0.2.4**（源码 checkout 或官方发布包都行）。
2. 下载并解压 `卫戍协议mod-跨版本一键安装包-v1.4.8-适配0.2.4.zip`。
3. 双击 `一键跨版本安装.bat`，输入 `1` 回车。
4. 装完 `cd /d 游戏目录 && npm start`。

无需 `--force`：`manifest.json` 里每个文件的 `original.sha256` 就是 v0.2.4 发布原文哈希，是一次干净的标准安装。备份在 `mod-fanpack\backup\`，菜单「5 卸载」可随时还原。

---

## ⚠️ 一次只装一个

拆分包之间、以及拆分包与整包，**改的是同一批文件**（`shared/protocol.js`、`public/js/ui/detailPanel.js`、`public/css/screens/game-panels.css`、`server/match/match/*.js`…）。

装了第二个会被安装器的「目标不是 release 原文」检查拦住。**想同时要多个功能，就装整包。**

例外：不同包改的文件完全不相干时可以叠加，但别指望它。

## 版本记录

- **v1.4.8（当前）**：新增**休整期自由更换技能和模组** —— 休整期（PREP）点开己方、未「准备」的干员详情，技能与精英模组下方各多一排切换按钮，点一下即改派。改动按「单干员增量」发给服务端合并进当前配发，**不会清掉其他干员已选的技能 / 模组**；已准备或不在休整期时按钮不出现，服务端也会拒绝。本功能此前是独立拆分包，现已并入整包。
- **v1.4.7**：删除装备详情卡底部的通用配发提示行（奇术的「拖拽至战场上的格子使用」保留）。
- **v1.4.6**：修复 Mon3tr 三技能「熔毁」回不了原位 —— 移动期间保留原部署位（同人版与自选版都已处理）。
- **v1.4.5**：清掉提卡兹之根 / M3利爪 / 灵巧钩索的 `[ASSUMED]` 开发注释，详情卡不再显示。
- **v1.4.0**：商店刷新偏向已激活盟约的装备（核心优先、等概率抽取），骑士戒律接入同一套偏向。
- **v1.3.3**：修正陨星、闪灵的特质文案（不改数值与结算）。
- **v1.3.2**：普通安装自动下载同人包必需的 58 份图片 / 战斗模型（约 3.4 MB）。
- **v1.3.1**：口径开关「满练度」同时把全体干员信赖拉到 100%。
