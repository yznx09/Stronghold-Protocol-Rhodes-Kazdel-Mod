# 拆分包一览

「拆分包」= **只装一个功能**的独立安装器。每个包里都是同一套结构：

```
<包名>/
├── install.mjs             ← 安装器（安装 / 校验 / 卸载）
├── 一键安装卸载.bat          ← 双击即可（部分包有）
├── manifest.json           ← 清单：每个文件的上游原文 sha256
├── payload/                ← 要覆盖 / 新增的文件本体
├── README.md / 安装说明.md  ← 这个包改了什么
└── 用法.txt                ← 部分包附带
```

> **完整清单（41 个包，原名 ↔ Release 下载名对照）在 [MOD-LIST.md](../MOD-LIST.md)** —— 本文只讲共性与怎么挑。

---

## 一、按上游版本挑

本仓库的包跨越上游 **0.2.4 / 0.2.5 / 0.3.x** 三代，**版本对不上会被安装器的「目标不是 release 原文」检查拦住**（强行 `--force` 会把上游的新改动覆盖掉）。能确认目标版本的：

| 包 | 目标上游 |
| --- | --- |
| 合并版整合包 v1.6.0 | **0.3.0** |
| 无限卡池 `unlimited-pool-mod.zip` | **0.3.0** |
| 湮灭模拟 `annihilation-sim-v3.1.7.zip` | **0.3.0** |
| 测试模拟 `test-sim-forge-workshop-v1.0.0.zip` | 基于湮灭模拟 v3.0.0 |
| 同盟模拟人数修改 `alliance-seats-mod.zip` | **0.2.5** 引擎 |
| 干员部分修复 `op-fixes-mod.zip` | **0.2.4**（包里明写「只适用于 0.2.4」） |
| 大厅在线音乐 `sp-lobby-music-online-v1.9.0.zip` | 需先装大厅界面 UI（`sp-lobby-ui-hubui-*`），具体见包内 `安装说明.md` |
| 其余拆分包 | 以包内 `README.md` / `manifest.json` 为准 |

拿不准时：先 `node install.mjs "<游戏目录>" --dry-run`，它只打印要做什么、不写文件；版本不符会在这一步报出来。

## 二、怎么装

```bat
node install.mjs "<游戏目录>"              :: 安装（覆盖前自动备份）
node install.mjs "<游戏目录>" --dry-run    :: 只看要做什么
node install.mjs "<游戏目录>" --verify     :: 校验装的文件还是不是本包的字节
node install.mjs "<游戏目录>" --uninstall  :: 还原成装之前
```

包里有 `一键安装卸载.bat` 的直接双击，选「1 检查并安装」。装完**重启游戏服务器**。

前置条件：Node.js **22+**；游戏目录是含 `public/`、`server/`、`shared/` 的那一层。备份在 `<游戏目录>\mod-<包名>\backup\`。

## 三、共存规则（最重要的一条）

**拆分包之间互相冲突**——它们改的是同一批文件（`shared/protocol.js`、`public/js/ui/detailPanel.js`、`public/css/screens/*.css`、`server/match/match/*.js` 等）。同一个文件只能有一个版本。

- 装第二个时会被安装器的「目标不是 release 原文」检查拦下，这是**保护**，不是 bug。
- **想同时要多个功能 → 装整合包**，别手动叠加拆分包。
- 确实要叠加时：先 `--uninstall` 全部还原，再按依赖顺序逐个装，每装一个跑一次 `npm start` 确认能起来。
- 改文件完全不重叠的包理论上可以叠加，但不要指望它 —— 上游每版都在动同样的文件。

### 已知的依赖关系

| 包 | 依赖 |
| --- | --- |
| 大厅在线音乐（hubmusic） | 大厅界面 UI（hubui）—— ♫ 按钮和音乐面板是 hubui 带来的，且**需要重启服务器** |
| 湮灭模拟 / 测试模拟 / 同盟模拟 | 三者改同一批文件，原作者是靠一份「合并补丁」让它们共存的（该补丁打包了官方素材，**不随仓库分发**） |
| 各房间 / 大厅 UI 类 | 互相覆盖，一次只留一个 |

## 四、挑包的思路

| 你想要的 | 去哪 |
| --- | --- |
| 一次装全 / 不想排冲突 | [整合包使用说明](整包-使用说明.md) —— 按上游版本选一个整合包 |
| 只要某一个小功能 | [MOD-LIST.md](../MOD-LIST.md) 按分类找拆分包 |
| 只想开 / 关同人内容 | 整合包里的 `一键开关mod.bat`（`mod.json` 的 `enabled`） |
| 找某个包在 Release 上的英文名 | [MOD-LIST.md](../MOD-LIST.md) 第 2 列 |
