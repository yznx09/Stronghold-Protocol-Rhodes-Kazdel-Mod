## 9. 表情包「发不出去」的真正原因（已修）

- 发送链路本身是通的（`g.emote` → 服务端 → `m.emote` 广播），但**气泡被队伍栏裁掉了**：本作的队伍栏
  `.team` 是可滚动容器（`overflow-y: auto; overflow-x: hidden`），而气泡按来源包的设计画在面板**外侧右边**
  （`.team__bubble { left: calc(100% + .06rem) }`），于是整块气泡被裁到只剩左边缘一条线，玩家看起来就是「点了没反应」。
  来源包的队伍栏没有滚动容器，所以它那边不裁。
- 修法（`game.css` 末尾）：队伍栏里的气泡改成落在**自己那一行**的中间并缩到 62%（`left:50%` +
  `translate(-50%,-50%) scale(.62)`），这样不会被裁剪，位置也贴着发送者头像。
- 现在点表情：面板收起、头像旁弹出气泡（约 3 秒）并播放表情音效；队友发的表情同样在自己的行上显示。
