# 拆分包一览（面向上游 0.2.x）

> **⚠️ 归档文档（历史版本）**
> 下表列的是 `mod拆分(最新版）.zip` 里那 11 个面向上游 **0.2.4 / 0.2.2** 的拆分包。
> 当前的拆分包清单以 [../拆分包一览.md](../拆分包一览.md) 与 [MOD-LIST.md](../../MOD-LIST.md) 为准 —— 已经到 41 个包，覆盖 0.2.4 / 0.2.5 / 0.3.x。

`mod拆分(最新版）.zip` 里是 11 个**互相独立、可单独安装**的 mod。每个文件夹里都有 `<包名>-mod/`（安装器 + payload）、`<包名>-mod-<版本>.zip`、以及一份 `用法.txt`。

装法（以某个包为例）：

```
cd /d 那个文件夹
node <包名>-mod\install.mjs <游戏目录>             装
node <包名>-mod\install.mjs <游戏目录> --dry-run   只看要做什么
node <包名>-mod\install.mjs <游戏目录> --verify    校验
node <包名>-mod\install.mjs <游戏目录> --uninstall 还原
```

**⚠️ 拆分包之间互斥**（改动同一批文件），一次只能装一个；想同时要多个功能请装整包。
