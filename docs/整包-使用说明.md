# 整合包使用说明（当前：合并版 v1.6.0 · 适配上游 0.3.0）

> **一句话**：下载 [`sp-merged-v1.6.0-for-0.3.0.zip`](https://github.com/yznx09/Stronghold-Protocol-Rhodes-Kazdel-Mod/releases/download/v1.6.0/sp-merged-v1.6.0-for-0.3.0.zip)，解压到**卫戍协议 v0.3.0** 游戏目录旁，双击 `一键跨版本安装.bat`：**首次装选「1 安装」**，**从旧版 mod 升上来选「2 强制覆盖安装 / 升级」**。

---

## 一、现有整合包有哪几个

「整合包」= 把多个拆分包合成一个安装器，一次装完。仓库里目前有三个，**按你的上游版本挑一个，不要混装**：

| 整合包 | Release | 目标上游 | 合并了哪些 |
| --- | --- | --- | --- |
| **合并版 v1.6.0** | [v1.6.0](https://github.com/yznx09/Stronghold-Protocol-Rhodes-Kazdel-Mod/releases/tag/v1.6.0) → `sp-merged-v1.6.0-for-0.3.0.zip` | **0.3.0** | 同人内容包 fanpack + 大厅界面 UI（hubui 20261014）+ 大厅轮播图（hubcarousel v2）+ 大厅栏位开关 1.3.2 + 语音语言修复 |
| 一键安装包 | [v1.5.4](https://github.com/yznx09/Stronghold-Protocol-Rhodes-Kazdel-Mod/releases/tag/v1.5.4) | 0.2.5（新 UI） | 同人内容包 + 新大厅 UI 一批改动 |
| 跨版本一键安装包 | [v1.5.3.1](https://github.com/yznx09/Stronghold-Protocol-Rhodes-Kazdel-Mod/releases/tag/v1.5.3.1) | 0.2.5 | 同人内容包，含源石弧修复 |

> **选哪个**：游戏是 **0.3.0** 就装 v1.6.0；游戏还是 **0.2.5** 就装 v1.5.4 / v1.5.3.1。版本对不上会被安装器的「目标不是 release 原文」检查拦住。
> 只要单一功能的，别装整合包，去 [MOD-LIST.md](../MOD-LIST.md) 挑拆分包。

## 二、环境要求

| 要求 | 说明 |
| --- | --- |
| 游戏版本 | 与整合包对应的上游版本（v1.6.0 → **0.3.0**） |
| Node.js | **22 或更新**（`node -v` 有输出即可） |
| 游戏目录 | 含 `public/`、`server/`、`shared/` 的那一层 |
| 磁盘 | 约 20 MB（另加可选的官方素材下载） |

## 三、怎么装（3 步）

### 第 1 步：解压

把 zip 解压到一个文件夹，**保持内部结构不变**（`payload/` 和 `install.mjs` 必须同级）。

### 第 2 步：双击 `一键跨版本安装.bat`

```
============================================================
  同人内容包 fanpack mod  -  一键安装
  目标版本:  卫戍协议：盟约  v0.3.0
============================================================
  [OK] node: v22.x
  [OK] 游戏目录: D:\...\Stronghold-Protocol
------------------------------------------------------------
  请选择操作
    1  安装（首次安装选这个：自动补齐必需图片，约 3.4 MB）
    2  强制覆盖安装 / 升级（旧版升级选这个：覆盖被改过的文件）
    3  安装 + 完整素材（官方图片 / 语音 / 时装，下载较大）
    4  只补齐缺失图片（已安装 mod 后选这个，约 3.4 MB）
    5  校验已安装的 mod
    6  卸载（还原游戏目录）
    7  退出
------------------------------------------------------------
```

- 脚本自动探测游戏目录（认 `data\chess.json`）；探测不到时，**把游戏目录拖到 `.bat` 上**再运行。
- 选 **1** 会顺带下载同人包必需图片（头像 / 立绘 / 技能图标 / M3利爪 / 战斗模型，约 3.4 MB）；想连官方立绘 / 语音 / 时装一起下就选 **3**（联网，较慢）。
- 已经装过、但看到干员头像显示首字或技能显示 S1/S2 占位，选 **4** 补齐即可，不用重装。
- **从上一版 mod 升级选 2**：游戏目录里被改过的文件会先备份再覆盖，等价于 `install.mjs --force`。

### 第 3 步：启动游戏

```bat
cd /d "<游戏目录>"
npm start
```

改的是服务端的部分（语音语言、栏目开关等）需要**重启服务器**才生效。

## 四、命令行 / 拖拽参数

不想用菜单时，直接把参数写给脚本：

```bat
一键跨版本安装.bat "<游戏目录>"              :: 普通安装
一键跨版本安装.bat "<游戏目录>" /force       :: 强制覆盖安装 / 升级
一键跨版本安装.bat "<游戏目录>" /verify      :: 校验已装内容
一键跨版本安装.bat "<游戏目录>" /uninstall   :: 卸载还原
一键跨版本安装.bat "<游戏目录>" /assets      :: 连带下载官方素材
```

也可以绕过 `.bat` 直接跑安装器：

```bat
node install.mjs "<游戏目录>" --force
node install.mjs "<游戏目录>" --dry-run
node install.mjs "<游戏目录>" --verify
node install.mjs "<游戏目录>" --uninstall
```

## 五、安装时会做什么

| 类别 | 说明 |
| --- | --- |
| **覆盖游戏文件** | 全部已三方合并到目标上游版本；覆盖前自动备份到 `<游戏目录>\mod-fanpack\backup\` |
| **新增文件** | 盟约素材、包内干员数据、UI 字符串包、换装 / 图鉴界面等 |
| **自检** | 安装末尾校验服务器能否载入内容包（`kazdelShip` / `rhodesShip`） |
| **必需图片**（自动） | 选 1 后自动下载约 3.4 MB 同人包必需素材，并修复 `data\assets.json` 条目；**本包不附带游戏版权素材** |
| **完整素材**（可选） | 官方图片 / 语音 / 时装由选 3 或 `--assets` 下载 |

安装过程逐行打印 `add` / `replace`，并写一份 `mod-fanpack\mod-manifest.json` 供 `--verify` / `--uninstall` 使用。

## 七、校验 / 升级 / 卸载

| 场景 | 做法 |
| --- | --- |
| 不确定装没装成功 | 菜单 **5 校验** 或 `install.mjs --verify` |
| 从旧版 mod 升上来 | 菜单 **2 强制覆盖安装 / 升级**（先备份再覆盖） |
| 装坏了想还原 | 菜单 **6 卸载**，按 `mod-fanpack\backup\` 精确还原 |
| 只想要官方口径 | `一键开关mod.bat`（对应 `mod.json` 的 `enabled=false`），服务器不合并 `packs/` |
| 只缺图片 | 菜单 **4 只补齐缺失图片** |

## 八、常见问题

**Q：装完游戏起不来？**
A：菜单 **6 卸载** 还原（从 `mod-fanpack\backup\` 恢复）。备份齐全，随时可退。

**Q：提示「目标版本不对 / 需要 --force」？**
A：说明你的游戏不是这个整合包对应的上游版本。确认版本号，或改用对应版本的整合包 / 拆分包。

**Q：提示脏文件、不敢强行装？**
A：说明目录里已有别的 mod 改过同一批文件。先 `--uninstall` 卸掉旧的，再装；只想升级同一套整合包时用菜单 2。

**Q：装完部分干员 / 技能 / 装备图片是占位？**
A：素材步骤没跑。菜单 **4 只补齐缺失图片**，或 `install.mjs "<游戏目录>" --assets --no-pipeline`，补完重启 `npm start` 再刷新页面。

**Q：`.bat` 双击闪退？**
A：`.bat` 为 GBK + CRLF。若仍异常，在 cmd 里 `cd` 到本目录手动执行，看报错信息。

**Q：能再叠加别的拆分包吗？**
A：改到同一批文件的不行。要多个功能就用整合包；单点功能用拆分包，具体见 [拆分包一览.md](拆分包一览.md)。
