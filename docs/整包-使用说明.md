# 卫戍协议 · 罗德岛卡兹戴尔盟约 Mod · 一键安装包（适配上游 v0.2.4）

> **一句话**：把本包解压到**卫戍协议 v0.2.4** 游戏目录旁，双击 `一键跨版本安装.bat`，选「1 安装」即可（会自动补齐必需图片）。

---

## 一、这个包是什么

本包是 **罗德岛 / 卡兹戴尔盟约同人内容包（fanpack mod v1.4.8）**，并**已完整适配上游 v0.2.4**。

mod 的内容（盟约 / 包内干员 / 装备 / 换装 / 语音音效 / 口径开关）是长在**上游代码**上的，上游每发一版都会改动一批同样的文件。
上一版包面向 **v0.2.3**；而 **v0.2.4** 又改了 **74 个文件**，其中 **32 个 mod 也动过**——直接装会被「脏文件」拦住，强行装则会把 0.2.4 的新改动覆盖掉。

本包已经**把这 32 个文件逐个做三方合并（base = 0.2.3，ours = mod，theirs = 0.2.4）**，产出的 `payload/` 就是**面向 v0.2.4 的成品**：

- 保留 mod 的全部内容与全部改动；
- 保留 0.2.4 的全部新功能与规则修正；
- `manifest.json` 里每个文件的 `original.sha256` 就是 **v0.2.4 的原文哈希**，所以**不需要任何 `--force`**，是一次干净的标准安装。

## 三、怎么用（3 步）

### 第 1 步：解压
把 `卫戍协议mod-跨版本一键安装包-0.2.4.zip` 解压到一个文件夹（保持内部结构不变）。

### 第 2 步：双击 `一键跨版本安装.bat`

```
============================================================
  同人内容包 fanpack mod  -  一键安装
  目标版本:  卫戍协议：盟约  v0.2.4
============================================================
  [OK] node: v22.x
  [OK] 游戏目录: D:\...\Stronghold-Protocol
------------------------------------------------------------
  请选择操作
    1  安装（推荐：自动补齐必需图片，约 3.4 MB）
    2  安装 + 完整素材（官方图片 / 语音 / 时装，下载较大）
    3  只补齐缺失图片（已安装 mod 后选这个，约 3.4 MB）
    4  校验已安装的 mod
    5  卸载（还原游戏目录）
    6  退出
------------------------------------------------------------
```

- 脚本自动探测游戏目录（认 `data\chess.json`）；找不到时，可**把游戏目录拖到本 `.bat` 上**再运行。
- 选 **1** 会自动下载同人包必需图片（头像 / 立绘 / 技能图标 / M3利爪 / 战斗模型，约 3.4 MB）；想连官方立绘 / 语音 / 时装一起下就选 **2**（需联网，较慢）；已经装过但看到首字 / S1 占位就选 **3**。

### 第 3 步：开始游玩

```
cd /d "<游戏目录>"
npm start
```

## 四、安装时会做什么

| 类别 | 说明 |
|---|---|
| **覆盖游戏文件**（106 个） | 全部已对齐 v0.2.4；覆盖前自动备份到 `<游戏目录>\mod-fanpack\backup\` |
| **新增文件**（38 个） | 盟约素材、包内干员数据、UI 字符串包、换装 / 图鉴界面等 |

安装过程会逐行打印 `add` / `replace`，并写一份 `mod-fanpack\mod-manifest.json`，供 `--verify` 与 `--uninstall` 使用。

## 六、本次更新做了什么（相对面向 0.2.3 的旧包）

1. **全量三方合并到 v0.2.4**：上游 0.2.4 改了 74 个文件，其中 **32 个 mod 也动过**，逐文件做了三方合并；
   19 个自动合并成功，**13 处冲突手工解决**（9 个代码文件 + 4 个语言文件）。
2. **关键冲突的处理方式**：
   - `screens/loadout.js`：上游把 `局内数值` 抽到了新文件 `ui/loadoutStats.js`；mod 的「精英化 / 等级 / 技能」标签行与 `trainLabel` **一并搬进新文件**，
     没有丢功能，也没有留下重复定义。
   - `server/match/pool.js` + `player/economy.js`：上游给道具池加了**共享库存**（`stock.canGain` / `stock.pick`），mod 给道具刷新加了**盟约偏向**（`prefer` / `chance`）。
     合并后两者同时生效：`rollItem(rng, maxTier, stock, { prefer, chance })`。
   - `screens/game.js`：mod 有意去掉了「结算语音」，上游在这个位置新增了「重新订阅战场元数据」；合并后**保留 mod 的语音口径、接入上游的新订阅**。
   - `data/config.json`：mod 只加了 `build.maxTraining / maxDeploy` 两个开关，其余全部取 0.2.4 的新数据（`poolCopiesOverrides` 等）。
   - `public/i18n/*.json`：按 mod「只加不改」的口径做结构化合并——**只增词条**，已有译文一律取上游。
3. **落地的验证**（都在 v0.2.4 树上跑过）：
   - `node tools/check-imports.mjs` —— 无违规（仅 `server/sim/nodeData.js` 是上游自带的既有条目）；
   - ESLint —— 合并后的 24 个 JS 文件 **0 error**（13 条 warning 全部是上游/mod 原有的）；
   - `node tools/golden.mjs --fast` —— **全部黄金场景（含 7 场完整人机对局）跑通无异常**；
   - `npm start` —— 服务器在 v0.2.4 + 本 payload 上正常启动，数据里已合并进 `fanpack` 内容包（25 个盟约 / 292 枚棋子）。

### 1.3.1 追加修正：满练度现在含「满信赖」

上游 `data/chess.json` 里每名干员的 `status` 都带着 `favorPoint 0`，构建期**不应用任何信赖加成**，
所以此前的「满练度」只有满级 / 满潜 / 专三 / 3 级模组，**干员的信赖加成一直是 0**（详情卡上的基础属性也写着「0 信赖的数值」）。

这一版按 [PRTS](https://prts.wiki/w/信赖值)（「干员信赖值达到 100% 后，属性加成达到上限」）的口径补上：

- **满练度 = 满级 + 满潜 + 专三 + 3 级模组 + 满信赖**：干员按 `character_table` 的 `favorKeyFrames` 最后一帧——
  也就是干员页上那个**信赖加成**——把 **生命上限 / 攻击 / 防御 / 法术抗性** 加到基础属性上（满信赖 = 100%，且 100% 即上限）；
  之后照常参与潜能与练度（自持有加成）的计算，与它们各自独立相加。
- 例：能天使的信赖加成是 **攻击 +90**（PRTS 干员页 `信赖加成_攻击=90`），满练度下她的基础攻击就 +90。
- **召唤物不吃信赖**（和潜能一样，只作用于干员本人）；**官方口径（开关关）仍然是 0 信赖**，与上游一致。
  开关的 ON / OFF 依旧是一键切换，`data/official.json` 里装的就是这份「满练度」补丁。
- 这一版**只改了 2 个数据文件**（`payload/data/official.json`、`payload/packs/fanpack/variants.json`），
  其余 142 个文件与 1.3.0 完全一致，所以安装、卸载、校验的行为都不变。

### 1.3.2 追加修正：普通安装自动补齐缺失图片

1.3.1 及以前把「仅安装」标成推荐，但没有同时下载同人包必需素材，导致部分包内干员头像显示首字、技能显示 S1/S2 文字、
M3利爪 等装备图标为空。1.3.2 起，选 **1 安装** 会自动：

- 下载 `asset-additions.json` 中的 **58 份必需图片 / 战斗模型（约 3.4 MB）**；
- 把 `asset-manifest-additions.json` 中的 **15 条资源清单**并入 `data\assets.json`；
- 完整官方图片、语音音效、时装仍放在选 **2**，避免普通安装被迫下载大体积素材。

如果你已经在旧包上装过 mod：双击本包脚本，选 **3 只补齐缺失图片** 即可，不需要卸载重装；若 `npm start` 正在运行，补完后请重启服务。

### 1.4.8 追加功能：休整期自由更换技能 / 模组

- 休整期（PREP，回合之间）点开**己方、尚未「准备」**的干员详情：技能名称下方出现一排技能切换按钮（S1 / S2 / S3…），精英模组的模组名下方出现一排模组切换按钮（含「未装备模组」）。
- 点一下就改派，立刻生效，不必等到下一局开局时的「干员调配」。
- 只改这一名干员：服务端把这次改动**增量合并**进你当前的配发，其他干员已选的技能 / 模组不受影响。
- 已「准备」、观战他人、或不在休整期时按钮不会出现；即使强行发包，服务端也会按阶段拒绝。

## 七、常见问题

**Q：装完游戏起不来？**
A：用菜单 **4 卸载**（从 `mod-fanpack\backup\` 恢复原文件）。备份齐全，随时可退。

**Q：提示「目标版本不对 / 需要 --force」？**
A：说明你的游戏不是 0.2.4。本包只支持 0.2.4；请先升级（应用上游的 `v0.2.4` 更新包即可）。

**Q：自选编队 / 数值 等界面会崩吗？**
A：不会。旧包的崩溃根因（用 0.2.2 版代码覆盖新版）在 1.2.0-cv 时已消除；本次 0.2.4 合并又保证了 0.2.4 的新代码没有被旧文件盖掉。

**Q：装完后部分干员 / 技能 / 装备图片是占位？**
A：这是 1.3.1 及以前未执行素材步骤导致的。用 1.3.2 包双击脚本选 **3 只补齐缺失图片**；或在游戏目录运行 `node mod-fanpack\install.mjs <游戏目录> --assets --no-pipeline`。完成后重启 `npm start`（服务未运行则直接启动）再刷新页面即可。

**Q：`.bat` 双击闪退？**
A：本 `.bat` 为 GBK + CRLF，无延迟展开、无嵌套 `for`。若仍异常，在 cmd 里 `cd` 到本目录手动执行 `一键跨版本安装.bat` 查看报错。
